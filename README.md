# 第一人稱教室原型

瀏覽器版、第一人稱的教室場景，用 Vite + Three.js（JavaScript）製作。這一版只做一件事：讓玩家能在教室裡自由走動。
所有物件都用 Three.js 幾何體與材質建立。地板磚縫與天花板格線用程式產生的 canvas 貼圖，沒有載入任何外部模型、圖片或音效。

## 啟動

```bash
npm install
npm run dev
```

用瀏覽器開啟終端機顯示的網址（預設 http://localhost:5173/）。

## 操作

| 按鍵 | 功能 |
| --- | --- |
| 點擊畫面 | 鎖定滑鼠，開始操作 |
| 滑鼠 | 轉動視角（上下限制 ±85°） |
| W / A / S / D | 前 / 左 / 後 / 右移動（方向相對於視角） |
| Shift | 衝刺（2 m/s → 4 m/s） |
| F3 | 顯示 / 隱藏碰撞框（紅色線框） |
| ESC | 解除滑鼠鎖定 |

左上角會顯示玩家座標（x, z）與 FPS。

### 手機 / 平板

| 操作 | 功能 |
| --- | --- |
| 點一下 | 開始（進入觸控模式） |
| 螢幕左半邊拖曳 | 虛擬搖桿移動（按下處就是搖桿中心，推越遠走越快） |
| 螢幕右半邊拖曳 | 轉動視角 |
| 「跑」按鈕 | 切換衝刺 |
| 「框」按鈕 | 顯示 / 隱藏碰撞框 |
| ⛶ 按鈕 | 全螢幕（iPhone Safari 不支援，所以不會出現） |

兩隻手指可以同時操作：左手移動，右手轉頭。建議橫向使用。觸控相關數值在 `config.js` 的 `touch` 區塊。

**用手機開啟：** 電腦和手機連同一個 Wi-Fi，在電腦執行

```bash
npm run dev:lan
```

終端機會列出 `Network: http://192.168.x.x:5173/`，用手機瀏覽器開這個網址即可。如果打不開，請檢查電腦防火牆是否允許 5173 port。

## 程式結構

```
index.html          畫面、HUD 與開始提示的樣式
src/config.js       所有尺寸、顏色、速度、排列數量
src/main.js         renderer、場景、相機、渲染迴圈
src/room.js         地板、牆、柱子、天花板設備、門、白板、講桌、投影機、攝影機、喇叭、燈光
src/furniture.js    課桌椅（InstancedMesh），並回傳碰撞框
src/player.js       Pointer Lock、視角、移動、AABB 碰撞
src/debug.js        HUD 與 F3 碰撞框
src/touch.js        手機 / 平板觸控操作（虛擬搖桿、拖曳轉頭、按鈕）
reference/          實際教室照片
```

座標系統：x 為左右（-x 是門那面側牆，+x 是窗戶側牆），z 為前後（-z 是前牆，+z 是後牆），地板 y = 0。學生面向 -z。

碰撞做法：牆、柱子、講桌、每張桌子、每張椅子各用一個 AABB 表示，玩家視為邊長 2×radius 的正方形。移動時先算 X 軸、再算 Z 軸，撞到就貼齊邊緣，所以能沿著牆和桌椅滑動，不會卡住。每幀的位移會再切成小段，避免高速時穿過物件。

## 依照片做的判斷（和需求描述不同的地方）

1. **學生面向的是白板牆，不是攝影機牆。** 照片 1、4 的椅背朝向攝影機那面牆，椅面朝向白板，投影機鏡頭也對著白板與布幕。所以 PTZ 攝影機、左右兩個喇叭、凸出的柱子都放在**後牆**（攝影機通常裝在後牆拍講者），白板、講桌、布幕捲筒放在前牆。
2. **排數與每排組數比 6×6 多。** 照片看起來大約 7 排、每排 8 組（走道左右各 4 組），房間也因此比 9×8 m 大。目前設為寬 9.6 m、長 11.5 m。
3. **天花板高度較低。** 用門高 2.1 m 的比例推算，天花板約 2.7–2.9 m，目前設為 2.9 m。
4. **門的位置：** 兩扇門都在同一面側牆（-x）。靠後牆的是一扇單門，靠前牆的是一大一小的雙門（大片門上有小窗）。時鐘在雙門旁。對面側牆是窗戶，有 4 片捲簾。

## 待確認

- 學生面向哪面牆（目前依照片判斷為白板牆）
- 實際排數、每排組數，以及是否真的有 1.2 m 的中央走道（照片中的桌距看起來相當平均）
- 柱子沿後牆的確切位置；是否還有其他柱子
- 兩扇門與前後牆的確切距離
- 白板、布幕、講桌的確切位置與尺寸
- 天花板燈管、出風口、吊扇的實際排列
- 牆面裝飾（喇叭、攝影機、白板、投影機）的座標寫在 `room.js`，是絕對座標，不會跟著房間尺寸縮放。把房間改得很小時，這些物件可能需要手動調整。

## 效能

- 課桌椅用 InstancedMesh 繪製，同材質的零件合成一次 draw call
- 只有一盞方向光產生陰影。場景是靜態的，陰影只計算一次（`shadowMap.autoUpdate = false`）
- PointLight 預設 4 盞，不產生陰影（`lighting.pointLightCount`）
- pixel ratio 上限：桌機 1.5（`render.maxPixelRatio`），觸控裝置 1.25（`render.touchMaxPixelRatio`）。如果 FPS 不夠，可以調低這個值或 `shadowMapSize`

## 走廊與開門（第二輪）

- **開門**：站到教室後方那扇門附近（約 1.4 m 內），畫面上方會出現提示。按 **E** 開門或關門；手機用右側「門」鈕。
- **走廊**：門開後可以走到教室外的走廊。走廊依照照片：窗戶與捲簾在一側，其他教室的門、告示板、滅火器箱在另一側，天花板是格板燈，地板是深灰磚加淺色導引線。
- 門板開啟時不擋人（原型簡化）。站在門板擺動範圍內時無法關門。
- 走廊兩端是牆，目前只能在走廊內走動，沒有其他樓層或走廊盡頭的空間。

### 新增檔案

## 第三輪：前門、延伸的走廊

- **教室前門**（雙門）：從走廊按 E 或「門」鈕開關。位置在教室前段（距前牆約 0.2 m，寬 1.5 m）。
- **走廊方向**：站在後門外面對窗戶，左手邊（+z）是電梯端，沒有門；右手邊（-z）是教室前門，再往前依序是茶水間、廁所、K410 電腦教室、403 多功能展演廳的門（裝飾，不能開）。
- 走廊延伸：前門側（-z）8.25 m、電梯端（+z）3.25 m（`config.js` 的 `frontExtend` / `backExtend`）。
- 電梯端的牆面有兩部電梯門、中間紅磚柱（照片估計）。天花板吊掛綠色指示牌。

### 待確認

- 教室前門的寬度與位置（目前雙門 1.5 m，距前牆 0.2 m）
- 茶水間、廁所、K410、403 門的位置與順序（目前是照片的順序猜測）
- 走廊的實際長度與電梯端的位置

## 第四輪：後門向教室內開

- 後門向教室內開，打開後門板貼在後牆上（樞軸在後牆端）。門口位於後牆角落，所以要走在門口範圍內（靠近後牆、約 z 5.05 以後）才能穿過；門框會擋住太靠前的路線。
- 門板擺動範圍內有人時不能關門。
- 前門仍然向走廊開。
